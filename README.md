# Shuvo Raj — Portfolio Website

A responsive, multi-page static portfolio built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages or Cloudflare Pages.

## Run locally
Open `index.html` in a browser, or use a local static server.

## Deploy to Cloudflare Pages (Git integration)
1. Create a GitHub repository, for example `shuvo-raj-portfolio`.
2. Upload all files and folders in this project to the repository root.
3. In Cloudflare Dashboard, open **Workers & Pages → Create → Pages → Connect to Git**.
4. Select the repository.
5. Framework preset: **None**.
6. Build command: leave blank.
7. Build output directory: `/` (project root).
8. Deploy.

No PHP runtime or build step is required for this static version. The Newspaper and E-Commerce project pages describe work categories; add verified live links, screenshots and details before publishing. The contact links work, but no server-backed contact form is configured.
